## Coverage statement

All four named sibling sets were compared. Set 1 (four hook consumers) was tabulated property by
property; the table above is the full comparison. Set 2 (fifteen lens agents) was compared on
frontmatter (all six keys, all fifteen files), on the four house boilerplate paragraphs, and on the
full `##` heading sequence. Set 3 (eight smoke suites) was compared on scratch-dir creation, trap
arms and cleanup for every `mktemp -d` and `harness_scratch_dir` call site. Set 4 (guarded capture
and guarded source) was compared across the four hook consumers, `edm-repo-readiness`, `edm-state`
and `_edm-datadir-lib.sh`; the `bin/tests/` and `evals/` call sites were sampled rather than
enumerated exhaustively, so the surviving-style inventory there is partial.
