# Lens L12 -- Silent Failures (round 1, full)

Scope: `git diff main..HEAD -- plugins/edm/` on branch `edm/edmv4-ecc-integration`.
Focus per this lens's mandate: failure paths that produce no observable signal, and
"everything is fine" reports indistinguishable from "nothing ran".

Nine of the sixteen findings below were reproduced live against scratch fixtures, each with a
positive control proving the check was capable of the opposite result. Those are marked
**[reproduced]** and carry the exact commands' observed output in their What's Wrong column.

## Method notes

Reproductions were run against `mktemp -d` scratch trees with `CLAUDE_PROJECT_DIR`,
`CLAUDE_PLUGIN_DATA` and `EDM_SRD_ROOT` redirected into them; no file in the repository under
audit was created, modified or read-locked, and no smoke suite was executed (`run-all.sh` performs
real `git checkout -b` through `edm-init`, so it was deliberately not run from an audit agent).
Each reproduction paired the failing case with a positive control that produced the opposite
result, so none of the nine rests on an assertion that could have been vacuously true.
