# Lens L5: Runtime Hygiene -- EDMV4 ECC Integration, pass 1, round 1 (full)

Scope: `git diff main..HEAD -- plugins/edm/`. Mandate is runtime file hygiene only: where files
created at runtime land, whether they are gitignored, whether they show as untracked in
`git status` on a deployment host, and whether they accumulate without cleanup. Concurrency (L3),
test quality (L4) and portability (L8) are out of scope here and were left to those lenses even
where the same line of code carries a defect in both dimensions.

Baseline `.gitignore` (repository root, 41 lines) covers, in the relevant part:
`.claude/`, `.edm-state.json.bak`, `.edm-state.json.tmp.*`,
`plugins/edm/docs/audit-patterns/*.lock*`, `plugins/edm/docs/audit-patterns/*.tmp.*`,
`**/.edm-state.lock*`, `**/*.lock`, `**/*.lockd*`, `**/*.md.tmp.*`, `plugins/edm/docs/*.tmp.*`.
Every "no" in the table below was checked against that exact list.

## Coverage statement

Areas covered: (1) the `SCRIPT_DIR`-then-`rm` class across `bin/tests/*.sh` -- swept all eight
suites plus `_harness.sh`, `timing.sh` and `run-all.sh` by redirection-target pattern; three
instances found, all in `wave8-smoke.sh`, all in-repo and none gitignored. (2) the harvested
patterns delta and its resolver -- resolved path, gitignore status and accumulation behaviour all
determined. (3) `edm-gateguard`'s session state and marker -- paths, caps, staleness and orphan
behaviour all determined; `edm-stop-gate` and `edm-bash-gate` confirmed to write nothing.
(4) `mktemp -d` scratch dirs and their traps across the suites -- `wave8-smoke.sh`'s trap chain
enumerated in full; `wave6`/`wave7`/`harness`/`timing` confirmed to install a suite-level trap,
and all three `evals/` staging sites confirmed four-arm trapped (L5-019).

Not covered: the `skills/` markdown surface was checked only for `edm-repo-readiness --json` and
worktree usage, not swept exhaustively for agent-instructed file writes outside `SRD/`; and the
`agents/` markdown surface was not swept at all for instructed runtime-file writes. Both are prose
that instructs an agent rather than code that creates a file, so they are a lower-yield surface for
this lens, but the gap is real and is recorded here rather than left implicit.
