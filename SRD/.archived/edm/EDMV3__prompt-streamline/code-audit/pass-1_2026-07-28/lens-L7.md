## Noted / Not Actionable
- `edm-check-grants`'s actor-first output shape -- deliberate and documented, required by its own AC7. Only the ignore-marker helpers should be shared.
- `edm-check-grants:136-138` not applying fence-skipping to source 2 -- deliberate and correct: the lens launch template lives inside a fence, and skipping it would blind the checker to the instruction it exists to catch. The model F1 should follow.
- `edm-check-vocabulary` carrying both a long header and a short sentinel block -- an abridgement with no contradiction; folds away if F2 lands.
- `edm-compare-eval:31` `set -uo` -- justified by its exit-status captures; only the missing comment is carried into F6.
- `eval:nightly` not using `*edm_rules` -- deliberate and documented; it needs a `when:` the shared rules cannot express.
- `test:smoke-bash32`'s floating tag -- an authorized named exception. The `apt-get` divergence in the same job is F9 and is **not** covered by that authorization.
- `test:state-validate` / `validate:plugin-cli` using `set -u` where `validate:manifest` uses `set -eu` -- both capture `$?` after a substitution, which `-e` would pre-empt. Justified.
- `lint:shellcheck` scanning `bin/*` only -- documented; test fixtures are intentionally loose.
- `implement/SKILL.md` having no curation block -- deliberate; Phase 6 presents no gate and the Convergence gate picks up what earlier phases left. (The residual hole -- prototype and fast-track/fix-pack skip code-audit entirely, so their QC stubs are never curated -- is mode-specific and belongs elsewhere.)
- The 17 agents without a `## Scope` section -- ticketed scope: AC1 names exactly thirteen files and requires byte-identity, verified in all thirteen.
- Four lenses having `## Process`, two a renamed equivalent, five none -- plausible per-lens specialization; recorded, not raised.
- Lens `description:` frontmatter in two styles -- both parse, and the manifest check accepts both. Cosmetic.
- Everything else across the eleven lens agents -- verified uniform: tools, model, effort, maxTurns, color, disallowedTools, the mandate sentence, the two-write-path output contract, the ASCII clause, the JSONL schema and all five enum bullets. Only the lens ID differs. This set is in good shape.
- `edm-test-scaffold.md`'s "class" vs "root" wording -- justified; it writes config files, not tests under one root.
- `argument-hint` quoting -- cosmetic YAML; the orchestrator's must be quoted.
- `run-all.sh:10` `set -uo` -- required, so the aggregator survives a failing suite.
- The three curation blocks' relative `docs/audit-patterns/*.md` path -- byte-consistent with each other, which is what this lens tests; whether it resolves at runtime is L11's finding.
- The three audit gates' severity handling and all eight Step 0 preflights -- checked; no gate defines a local scale, all reference the canonical Gate PROTOCOL by name, and the preflight text lives once with only the gated-command token substituted. No divergence.
