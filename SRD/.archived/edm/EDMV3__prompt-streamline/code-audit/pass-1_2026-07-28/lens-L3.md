## Noted / Not Actionable

- `_rmw_state_body:415-421` -- the write itself is correct; target only ever replaced by an atomic `mv`, and `jq` failure removes the temp and returns non-zero. A SIGKILL leaves a `.tmp.<pid>` but the state file is intact and the litter is not matched by `list_state_files`.
- CRLF in `pattern_insert_line_for` / the `grep -qxF` gate -- fails both matches, producing a clean documented skip naming file and heading. Fails safe.
- `update-patterns` with no trailing newline -- `head -n N` emits the unterminated line and the block begins with `printf '\n'`; only the separator blank line is lost.
- `update-patterns` empty target section -- `boundary == start + 1` gives insertion immediately after the heading. Correct.
- `update-patterns` interrupted between entries -- each entry is an independent atomic splice and a re-run recomputes from disk. Idempotent by construction.
- Filenames with spaces in `edm-lint-artifacts` -- array `FILES=("$@")` plus `IFS= read -r` handles them; only newlines break (L3-06).
- `is_ignored_line` with an empty set -- short-circuits on `[[ -n "$lineset" ]]`, and the `&& continue` position keeps `set -e` from firing.
- `report_violation`'s counter -- every consuming loop uses `< <(...)`, so the body runs in the current shell and the global increments survive. Easy to get wrong; correct here.
- `metrics-report` ratio arithmetic (`:2098`, `:2189`, `:2340`) -- every division guarded by `if $tc > 0 and $th > 0`; `--calibrate`'s `.[length / 2 | floor]` is an index and `group_by` never yields an empty group.
- `score_from_ratio` with denominator 0 -- explicitly returns 0, and `compute_dim5` guards before calling.
- `run_with_timeout` -- `sleep 1` polling drifts a few seconds and a recycled PID could in principle be signalled; both documented and immaterial at 2700s.
- `state_file_for` prefix validation (`:169`) -- the charset guard blocks traversal for every path-building caller and `migrate-path` re-checks it.
- `schema_at_least` with a non-numeric version -- degrades to warn-and-proceed; hand-edited-file territory, fails safe.
- `cmd_migrate_path` rollback (`:2424-2434`) -- genuinely rolls back on both failure paths; residue is an empty product directory.
